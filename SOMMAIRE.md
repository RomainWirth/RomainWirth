# SOMMAIRE

Ce document est le point d'entree principal pour parcourir les cours, notes et ressources du depot.

Il permet de naviguer rapidement entre les grandes familles de contenus, puis de rejoindre les points d'entree les plus utiles de chaque section.

## Commencer ici

Si tu decouvres le depot, l'ordre de lecture recommande est le suivant :

1. [README.md](./README.md) pour la vue d'ensemble du projet.
2. [culture_numerique/MEP_environnement.md](./culture_numerique/MEP_environnement.md) pour mettre en place l'environnement de travail.
3. Les fondamentaux : [Algorithmique](./Algorithmique/), [POO](./POO/), [HTML-CSS](./HTML-CSS/), [JS](./JS/).
4. Les parcours plus specialises : [TypeScript](./TypeScript/), [REACT](./REACT/), [GO](./GO/), [JAVA](./JAVA/), [PHP](./PHP/).
