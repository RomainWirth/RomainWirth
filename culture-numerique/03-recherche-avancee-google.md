# RECHERCHE AVANCEE GOOGLE

## Pourquoi apprendre a bien chercher ?

Savoir utiliser Google correctement est une competence essentielle dans les metiers du numerique.

Bien chercher permet de :

- trouver plus vite une information fiable ;
- reduire le bruit dans les resultats ;
- acceder a de la documentation plus pertinente ;
- mieux apprendre en autonomie.

Dans la pratique, une bonne recherche fait souvent gagner beaucoup plus de temps qu'on ne l'imagine.

## Une bonne recherche commence par une bonne formulation

Avant d'utiliser des operateurs avances, il faut deja savoir formuler clairement son besoin.

### Mauvaise approche

Faire une recherche trop vague :

```text
bug javascript
```

### Meilleure approche

Ajouter le contexte, l'outil, le message d'erreur ou l'objectif :

```text
javascript fetch cors error localhost
```

ou :

```text
react useeffect infinite loop explanation
```

## Les bons reflexes de recherche

### 1. Chercher avec les mots importants

Il faut garder les mots-clés utiles et supprimer les mots inutiles.

Exemple :

Au lieu de :

```text
comment faire pour centrer une div en css s'il vous plait
```

preferer :

```text
center div css
```

### 2. Ajouter le contexte technique

Souvent, il faut preciser :

- le langage ;
- le framework ;
- l'outil ;
- l'environnement.

Exemples :

```text
laravel validation custom rule
```

```text
postgres docker connection refused
```

```text
typescript object keys type safe
```

### 3. Chercher en anglais quand c'est technique

Pour les sujets de developpement, les meilleurs resultats sont souvent en anglais.

Exemple :

- en francais : `boucle infinie useEffect`
- en anglais : `useEffect infinite loop`

## Les operateurs utiles dans Google

Google comprend plusieurs operateurs qui permettent d'affiner fortement les resultats.

### Recherche d'expression exacte avec les guillemets

Utiliser des guillemets pour chercher une expression exacte.

Exemple :

```text
"Cannot read properties of undefined"
```

Tres utile pour :

- les messages d'erreur ;
- les citations ;
- les titres exacts.

### Exclure un mot avec le signe `-`

Permet de retirer des resultats non souhaites.

Exemple :

```text
python list comprehension -w3schools
```

Ici, on exclut les resultats provenant de contenus que l'on ne veut pas voir.

### Rechercher sur un site precis avec `site:`

Permet de limiter la recherche a un domaine ou un site.

Exemples :

```text
site:developer.mozilla.org fetch api
```

```text
site:stackoverflow.com react props typescript
```

```text
site:docs.nestjs.com guards
```

Tres utile pour cibler directement :

- une documentation officielle ;
- un forum ;
- un site de reference.

### Rechercher un type de fichier avec `filetype:`

Permet de chercher des fichiers d'un format donne.

Exemples :

```text
algorithmique filetype:pdf
```

```text
sql normalization course filetype:ppt
```

### Rechercher un mot dans le titre avec `intitle:`

Permet de privilegier les pages qui contiennent un mot donne dans leur titre.

Exemple :

```text
intitle:"docker compose" postgres
```

### Rechercher dans l'URL avec `inurl:`

Permet de viser certains chemins ou sections de site.

Exemple :

```text
inurl:docs react router
```

## Combiner plusieurs operateurs

Les operateurs deviennent tres puissants quand on les combine.

Exemple :

```text
site:developer.mozilla.org "flexbox" css
```

ou :

```text
site:github.com "awesome" golang
```

ou encore :

```text
site:stackoverflow.com "Cannot find module" typescript -angular
```

## Exemples concrets utiles en developpement

### Chercher une erreur exacte

```text
"Unexpected token export"
```

### Chercher dans une doc officielle

```text
site:react.dev useEffect
```

### Chercher une solution dans Stack Overflow

```text
site:stackoverflow.com node fetch timeout
```

### Chercher une explication pedagogique

```text
javascript closure explained
```

### Chercher un exemple de syntaxe

```text
sql join example
```

## Rechercher mieux, ce n'est pas seulement utiliser des operateurs

Il faut aussi savoir evaluer le resultat obtenu.

### Verifier la source

Toutes les pages n'ont pas la meme valeur.

En general, il faut privilegier :

- la documentation officielle ;
- les sites techniques reconnus ;
- les exemples recents ;
- les contenus correspondant a la bonne version de l'outil.

### Regarder la date

Dans le web et le developpement, une solution ancienne peut etre depassee.

Il faut donc verifier :

- la date de publication ;
- la version du langage ou du framework ;
- la pertinence actuelle de la solution.

### Recouper l'information

Quand un sujet est important, il vaut mieux comparer plusieurs sources plutot que croire la premiere page trouvee.

## Les erreurs frequentes en recherche web

- chercher avec une phrase trop longue et floue ;
- ne pas inclure le contexte technique ;
- ignorer le message exact d'erreur ;
- rester uniquement sur des sources peu fiables ;
- ne pas passer a l'anglais pour les sujets techniques ;
- ne pas reformuler quand les premiers resultats sont mauvais.

## Methode simple pour bien chercher

Quand une recherche ne donne rien, on peut proceder ainsi :

1. Identifier les mots-clés essentiels.
2. Ajouter le langage, l'outil ou le framework.
3. Utiliser les guillemets si on a un message exact.
4. Ajouter `site:` pour cibler une source fiable.
5. Reformuler si les resultats restent trop vagues.

## A retenir

- Bien chercher est une competence fondamentale.
- Une recherche efficace repose d'abord sur de bons mots-clés.
- Les operateurs comme `site:`, `filetype:`, `intitle:` et les guillemets sont tres utiles.
- En technique, chercher en anglais donne souvent de meilleurs resultats.
- Trouver une information n'est pas suffisant : il faut aussi verifier sa fiabilite.
