# RACCOURCIS CLAVIER ET NAVIGATION

## Pourquoi utiliser des raccourcis clavier ?

Les raccourcis clavier permettent d'executer une action rapidement sans passer par la souris.

Ils servent a :

- gagner du temps ;
- limiter les gestes repetitifs ;
- naviguer plus vite dans un systeme ou une application ;
- travailler de maniere plus fluide.

Dans les metiers du numerique, ils deviennent vite indispensables, car une grande partie du temps est passee a :

- ouvrir des fichiers ;
- changer de fenetre ;
- copier, coller, chercher, remplacer ;
- naviguer entre plusieurs outils.

## Deux idees importantes

### 1. Un raccourci n'est pas un gadget

Un raccourci ne sert pas seulement a aller plus vite. Il aide aussi a rester concentre sur sa tache.

Quand on evite de quitter le clavier toutes les 10 secondes, on perd moins le fil de ce qu'on est en train de faire.

### 2. Il faut apprendre par familles

Il est inutile d'essayer de memoriser 50 raccourcis d'un coup.

Le plus efficace est d'apprendre par groupes :

- edition de texte ;
- navigation dans les fenetres ;
- navigation web ;
- raccourcis de developpement.

## Les raccourcis les plus utiles sur le bureau

Les raccourcis "desktop" sont les raccourcis generaux du systeme d'exploitation.

Ils permettent de gerer les fenetres, les applications et les actions courantes.

### Raccourcis classiques

| Raccourci | Action |
| --- | --- |
| `Ctrl + C` | Copier |
| `Ctrl + V` | Coller |
| `Ctrl + X` | Couper |
| `Ctrl + Z` | Annuler |
| `Ctrl + Y` | Retablir |
| `Ctrl + A` | Tout selectionner |
| `Ctrl + S` | Enregistrer |
| `Ctrl + P` | Imprimer ou ouvrir rapidement selon le logiciel |
| `Ctrl + F` | Rechercher |

### Gestion des fenetres

| Raccourci | Action |
| --- | --- |
| `Alt + Tab` | Passer d'une fenetre a une autre |
| `Alt + F4` | Fermer la fenetre active |
| `Super` ou `Windows` | Ouvrir le menu principal |
| `Super + Fleche gauche/droite` | Ancrer une fenetre sur un cote de l'ecran |
| `Super + D` | Afficher le bureau |

Selon l'OS utilise, certains raccourcis varient un peu, mais les logiques restent proches.

## Differences entre Linux, Windows et macOS

Les raccourcis clavier ne sont pas totalement identiques selon le systeme d'exploitation, mais ils suivent souvent la meme logique.

L'idee generale est la suivante :

- sous Windows et Linux, on utilise tres souvent la touche `Ctrl` ;
- sous macOS, beaucoup de raccourcis equivalent utilisent la touche `Cmd` (`⌘`) ;
- la touche `Alt` sous Windows/Linux correspond souvent a `Option` sur Mac ;
- la touche `Windows` correspond globalement a la touche `Command` ou a certaines fonctions systeme sur Mac, selon le contexte.

### Exemples de correspondances frequentes

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Copier | `Ctrl + C` | `Cmd + C` |
| Coller | `Ctrl + V` | `Cmd + V` |
| Couper | `Ctrl + X` | `Cmd + X` |
| Annuler | `Ctrl + Z` | `Cmd + Z` |
| Tout selectionner | `Ctrl + A` | `Cmd + A` |
| Enregistrer | `Ctrl + S` | `Cmd + S` |
| Rechercher | `Ctrl + F` | `Cmd + F` |
| Fermer une fenetre ou un onglet | `Ctrl + W` ou `Alt + F4` | `Cmd + W` |
| Changer d'application | `Alt + Tab` | `Cmd + Tab` |

### Ce qui change surtout dans la pratique

#### Windows

Windows utilise beaucoup :

- `Ctrl` pour les actions courantes ;
- `Alt` pour la navigation systeme ;
- la touche `Windows` pour ouvrir le menu principal ou gerer les fenetres.

#### Linux

Sous Linux, cela depend un peu de l'environnement graphique utilise, mais on retrouve tres souvent une logique proche de Windows.

Les bases a retenir sont :

- `Ctrl` pour les actions de base ;
- `Alt + Tab` pour changer de fenetre ;
- `Super` pour designer la touche systeme, souvent equivalente a la touche `Windows` du clavier.

#### macOS

Sur Mac, il faut surtout s'habituer a la touche `Cmd` (`⌘`), qui remplace la plupart des usages de `Ctrl` pour les raccourcis quotidiens.

Par exemple :

- copier : `Cmd + C` ;
- coller : `Cmd + V` ;
- enregistrer : `Cmd + S`.

La touche `Ctrl` existe aussi sur Mac, mais elle n'a pas le meme role principal que sous Windows ou Linux.

### Le bon reflexe

Quand on change de systeme, il ne faut pas essayer de reapprendre tous les raccourcis depuis zero.

Le plus utile est de retenir les equivalences :

- `Ctrl` devient souvent `Cmd` ;
- `Alt` devient souvent `Option` ;
- la logique des actions reste globalement la meme.

Autrement dit, on change surtout de touches, pas de facon de travailler.

## Les raccourcis dans le navigateur

Les raccourcis de navigation web sont tres utiles pour consulter rapidement plusieurs pages, chercher une information et se deplacer sans perdre de temps.

### Navigation de base

| Raccourci | Action |
| --- | --- |
| `Ctrl + T` | Ouvrir un nouvel onglet |
| `Ctrl + W` | Fermer l'onglet actif |
| `Ctrl + Shift + T` | Reouvrir le dernier onglet ferme |
| `Ctrl + Tab` | Passer a l'onglet suivant |
| `Ctrl + Shift + Tab` | Revenir a l'onglet precedent |
| `Ctrl + L` | Selectionner la barre d'adresse |
| `Ctrl + R` | Recharger la page |
| `Ctrl + D` | Ajouter la page aux favoris |
| `Ctrl + H` | Ouvrir l'historique |

### Recherche et lecture

| Raccourci | Action |
| --- | --- |
| `Ctrl + F` | Rechercher un mot dans la page |
| `Ctrl + +` | Zoomer |
| `Ctrl + -` | Dezoomer |
| `Ctrl + 0` | Reinitialiser le zoom |
| `Espace` | Descendre dans la page |
| `Shift + Espace` | Remonter dans la page |
| `Home` | Aller en haut de la page |
| `End` | Aller en bas de la page |

## Les raccourcis utiles pour la navigation clavier

Dans beaucoup d'interfaces, on peut se deplacer sans souris.

### Touches frequentes

| Touche | Usage |
| --- | --- |
| `Tab` | Passer a l'element suivant |
| `Shift + Tab` | Revenir a l'element precedent |
| `Entree` | Valider une action |
| `Echap` | Fermer, annuler ou quitter un menu |
| `F5` | Actualiser dans certains contextes |
| `F11` | Plein ecran dans le navigateur |

La touche `Tab` est particulierement importante pour l'accessibilite et pour les utilisateurs qui naviguent beaucoup au clavier.

## Raccourcis et productivite en developpement

Quand on code, certains raccourcis deviennent vite essentiels :

- rechercher dans un fichier ;
- ouvrir un fichier rapidement ;
- basculer entre l'editeur et le terminal ;
- commenter du code ;
- formatter un fichier.

Exemples frequents dans un editeur comme VS Code :

| Raccourci | Action |
| --- | --- |
| `Ctrl + P` | Ouvrir un fichier rapidement |
| `Ctrl + Shift + P` | Ouvrir la palette de commandes |
| `Ctrl + /` | Commenter ou decommenter une ligne |
| `Ctrl + Shift + F` | Rechercher dans tout le projet |
| `Ctrl + J` | Afficher ou masquer le terminal / panneau selon la configuration |

## Comment apprendre les raccourcis efficacement ?

### Commencer petit

Choisir d'abord 5 a 10 raccourcis utiles au quotidien :

- copier ;
- coller ;
- annuler ;
- rechercher ;
- changer de fenetre ;
- ouvrir un onglet.

### Les reutiliser tous les jours

Le but n'est pas de les connaitre "en theorie", mais de les transformer en reflexes.

### Apprendre selon son usage reel

Les meilleurs raccourcis sont ceux qu'on utilise souvent.

Un developpeur n'aura pas exactement les memes priorites qu'un utilisateur bureautique ou qu'un designer.

## A retenir

- Les raccourcis clavier font gagner du temps et de la concentration.
- Ils existent a plusieurs niveaux : systeme, navigateur, editeur, logiciel.
- Il vaut mieux apprendre peu de raccourcis, mais bien les utiliser.
- Les raccourcis deviennent rapidement des automatismes tres utiles dans le travail quotidien.
