# INTRODUCTION AU WEB

## Qu'est-ce que le Web ?

Le Web est un service d'Internet qui permet de consulter des pages et des ressources à l'aide d'un navigateur.

Quand on ouvre un site dans Chrome, Firefox ou Edge, on utilise le Web.

Le Web repose principalement sur :

- des pages ou applications accessibles par une adresse ;
- des navigateurs pour les afficher ;
- des liens hypertextes pour passer d'une ressource à une autre.

## Internet et Web : quelle différence ?

On confond souvent Internet et Web, mais ce n'est pas la même chose.

### Internet

Internet est le réseau mondial qui relie des millions de machines entre elles.

Il permet de faire fonctionner plusieurs services, par exemple :

- le Web ;
- les emails ;
- le transfert de fichiers ;
- la messagerie instantanée ;
- certains services de streaming, de cloud ou de visioconférence.

### Le Web

Le Web est seulement l'un de ces services.

On peut donc résumer ainsi :

- Internet = l'infrastructure reseau ;
- Web = un service qui utilise cette infrastructure.

## Comment fonctionne le Web ?

Quand un utilisateur consulte un site, plusieurs elements interviennent :

1. L'utilisateur saisit une adresse web, aussi appelee URL.
2. Le navigateur envoie une requete a un serveur.
3. Le serveur repond en envoyant des ressources : HTML, CSS, JavaScript, images, etc.
4. Le navigateur interprete ces fichiers et affiche la page.

## Les principaux acteurs du Web

### Le navigateur

Le navigateur est le logiciel qui permet d'afficher les pages web.

Exemples :

- Google Chrome ;
- Mozilla Firefox ;
- Microsoft Edge ;
- Safari.

### Le serveur

Le serveur est la machine ou le service qui heberge les ressources du site et repond aux demandes des utilisateurs.

### Les langages du Web

Les technologies fondamentales du Web sont :

- HTML : structure le contenu ;
- CSS : gere la mise en forme ;
- JavaScript : ajoute le comportement et l'interactivite.

## Bref historique

- 1969 : ARPANET pose les bases des reseaux modernes.
- 1971-1972 : les premiers systemes d'email se democratisent.
- 1989-1991 : Tim Berners-Lee propose puis met en place le World Wide Web.
- 1991 : apparition des premieres pages web accessibles publiquement.

Le Web s'est ensuite developpe tres rapidement avec les navigateurs, les moteurs de recherche, le commerce en ligne, les reseaux sociaux puis les applications web modernes.

## Pourquoi cette distinction est importante ?

Comprendre la difference entre Internet et le Web aide a mieux comprendre :

- le role d'un navigateur ;
- la communication entre client et serveur ;
- la place du HTML, du CSS et du JavaScript ;
- le fonctionnement general d'un site ou d'une application web.

## A retenir

- Internet est le reseau.
- Le Web est un service qui fonctionne sur ce reseau.
- Un navigateur permet d'acceder aux ressources du Web.
- Un site web repose sur des echanges entre un client et un serveur.
