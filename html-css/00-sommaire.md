## Objectif du module

Ce module sert a apprendre progressivement :

- la structure d'une page avec HTML ;
- la mise en forme avec CSS ;
- la methode de travail pour lier les deux proprement.

## Conseil de progression

- lire un chapitre ;
- refaire les exemples a la main ;
- faire les mini-exercices ;
- passer au chapitre suivant seulement apres validation.
