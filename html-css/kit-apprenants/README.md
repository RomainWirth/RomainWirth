# Kits apprenants - HTML & CSS

Deux parcours pour apprendre HTML & CSS par la pratique, autour du **même projet fil rouge** : *Ma Vitrine*, un site web d'une page (mini-portfolio) construit section par section, propre et responsive.

Le résultat final est le même - seul le **rythme** change.

---

## Choisir sa version

| | [Version complète - 5 jours](./html-css-5j/README.md) | [Version compacte - 3 jours](./html-css-3j/README.md) |
|---|---|---|
| **Pour qui ?** | Débutant complet | A déjà touché au HTML/CSS ou apprend vite |
| **Rythme** | Progressif, détaillé | Soutenu, à l'essentiel |
| **HTML** | 2 jours | 1 jour |
| **CSS & mise en page** | 3 jours | 2 jours |
| **Mise en ligne** | Jour dédié | Bonus optionnel |

> 💡 **En cas de doute, commence par la version 5 jours.** Tu peux toujours accélérer en sautant ce que tu maîtrises. La version 3 jours suppose que tu es déjà à l'aise avec les bases (créer des fichiers, notions de balises).

---

## Le projet fil rouge : *Ma Vitrine*

Une page vitrine personnelle avec :
- un **en-tête** + navigation ;
- une section **« À propos »** ;
- une **galerie** de cartes (projets) ;
- un **formulaire de contact** ;
- un **pied de page**.

Le tout **responsive** (adapté au mobile), en HTML et CSS uniquement (pas de JavaScript). Thème adaptable (restaurant, voyage, club...).
