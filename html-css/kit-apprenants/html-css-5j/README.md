# Ma Vitrine - Apprendre HTML & CSS par la pratique

**Kit apprenant - Version débutant**
5 jours | HTML5 & CSS3 | Aucun prérequis

> Ce kit t'amène de zéro à un **site web d'une page**, propre et responsive, que tu construis section par section. Pas de JavaScript : uniquement HTML (la structure) et CSS (l'apparence).
>
> À la fin, tu auras une **page vitrine personnelle** (mini-portfolio) en ligne, réutilisable pour te présenter.

## Le projet fil rouge : *Ma Vitrine*

Tout au long des 5 jours, tu construis la **même page**, enrichie chaque jour :

- un **en-tête** avec le titre du site et une navigation ;
- une section **hero** (accroche de présentation) ;
- une section **« À propos »** ;
- une **galerie** de cartes (projets, centres d'intérêt...) ;
- un **formulaire de contact** ;
- un **pied de page**.

Le thème « portfolio personnel » est un exemple : tu peux l'adapter (page d'un restaurant, d'un lieu de voyage, d'un club...). La structure et le code restent les mêmes.

---

## Comment utiliser ce kit

- **Un jour = un fichier.** Suis les jours dans l'ordre, ils sont progressifs.
- Chaque jour contient : des **objectifs**, des **explications**, des **tâches** (qui construisent réellement ton site) et un **livrable** (checklist de fin de journée).
- Les sections **⚡ Pour aller plus loin** sont optionnelles.
- Contrairement aux kits de programmation, il n'y a pas de « corrections » à part : tu vérifies ton résultat **directement dans le navigateur**. La bonne réponse, c'est une page qui s'affiche comme prévu.
- Pour la théorie détaillée, appuie-toi sur le cours du dossier parent : [`../../00-sommaire.md`](../../00-sommaire.md).

## Prérequis techniques

- Un **navigateur** moderne (Chrome, Firefox, Edge...).
- Un **éditeur de code** (VS Code recommandé).
- Savoir créer des dossiers et des fichiers.

> 💡 **Installe l'extension « Live Server » dans VS Code** : elle ouvre ta page dans le navigateur et la recharge automatiquement à chaque modification. Indispensable pour voir tes changements en direct.

## Durée indicative

Compte une demi-journée à une journée par chapitre en autonomie. Le jour 4 (mise en page) est le plus dense.

> ⏩ Une version **compacte en 3 jours** pourra être ajoutée plus tard pour un apprentissage plus rapide.
