## Le projet fil rouge : *Ma Vitrine*

Une **page vitrine personnelle** (mini-portfolio) construite en 3 jours :
- un **en-tête** avec titre + navigation ;
- une section **« À propos »** ;
- une **galerie** de cartes (projets) ;
- un **formulaire de contact** ;
- un **pied de page**.

Thème adaptable (restaurant, voyage, club...) : la structure et le code restent les mêmes.

---

## Mode d'emploi

- Un jour = un fichier, dans l'ordre.
- Chaque jour : **objectifs**, **explications condensées**, **tâches** (construction du site), **livrable**.
- Sections **⚡ Pour aller plus loin** optionnelles.
- Pas de fichier de corrections : tu vérifies ton résultat **dans le navigateur**.
- Pour approfondir une notion, consulte la [version 5 jours](../html-css-5j/README.md) et le [cours complet](../../00-sommaire.md).

## Prérequis techniques

- Un **navigateur** moderne + un **éditeur** (VS Code recommandé).
- Savoir créer dossiers et fichiers.

> 💡 Installe l'extension **Live Server** dans VS Code pour recharger la page automatiquement à chaque modification.

## Note sur la mise en ligne

La publication du site est présentée en **bonus optionnel** au jour 3 : elle n'est pas indispensable pour maîtriser HTML/CSS. La procédure détaillée se trouve dans la [version 5 jours (jour 05)](../html-css-5j/jour-05.md).
