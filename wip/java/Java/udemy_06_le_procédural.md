## Le mode Debug

Pour utiliser le mode debug, il faut ajouter des points d'arrêt dans l'IDE au niveau des lignes que l'on souhaite vérifier. 
Lorsqu'on lance le programme, cela permet d'exécuter le code jusqu'au point d'arrêt défini. 
L'IDE permet de lancer le programme en mode `debug`. 
On pourra de cette manière exécuter le code pas à pas, de point d'arrêt en point d'arrêt, permettant de vérifier la bonne exécution du programme.
