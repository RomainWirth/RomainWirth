# Exercices - Introduction au clean code

Ce dossier contient les exemples du chapitre d'introduction, separes en scripts executables.

## Fichiers

- 01-boys-scout-todo-avant.js
- 01-boys-scout-todo-apres.js
- 02-lisibilite-avant.js
- 02-lisibilite-apres.js
- 03-dry.js
- 04-gestion-erreurs.js

## Execution

Depuis ce dossier:

```bash
node 01-boys-scout-todo-avant.js
node 01-boys-scout-todo-apres.js
node 02-lisibilite-avant.js
node 02-lisibilite-apres.js
node 03-dry.js
node 04-gestion-erreurs.js
```

Objectif pedagogique:
- lire d'abord les extraits dans le cours pour comprendre les principes,
- executer ensuite les scripts pour observer les comportements,
- modifier les scripts pour pratiquer le refactoring.
