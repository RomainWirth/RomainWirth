# Kits apprenants - Git & GitHub

Deux parcours pour apprendre Git & GitHub par la pratique, autour du **même projet fil rouge** : *Mon premier dépôt* - versionner un projet, le publier sur GitHub et faire sa première pull request.

Le résultat final est le même - seul le **rythme** change.

---

## Choisir sa version

| | [Version complète - 5 jours](./git-github-5j/README.md) | [Version compacte - 3 jours](./git-github-3j/README.md) |
|---|---|---|
| **Pour qui ?** | Débutant complet | À l'aise avec le terminal ou déjà croisé Git |
| **Rythme** | Progressif, détaillé | Soutenu, à l'essentiel |
| **Git local** | 2 jours | 1 jour |
| **Branches & GitHub** | 2 jours | 1 jour |
| **Collaboration** | 1 jour | 1 jour |

> 💡 **En cas de doute, commence par la version 5 jours.** Tu peux accélérer en sautant ce que tu maîtrises. La version 3 jours suppose une aisance de base avec le terminal.

---

## Le projet fil rouge : *Mon premier dépôt*

Tu versionnes un petit projet de ton choix (ton site *Ma Vitrine* du kit HTML, ou un carnet de notes en Markdown), tu le publies sur GitHub, et tu fais ta première **pull request**.

Le livrable final : un **dépôt GitHub propre** (historique clair, README, branches) et une **contribution** à un projet collectif.

---

## Le dépôt collectif *Le Mur des Apprenants*

La pratique des pull requests (jour 5 en version longue, jour 3 en version courte) s'appuie sur un **dépôt collectif** où chaque apprenant contribue via une PR - un exercice qui fonctionne en solo, en asynchrone et à toute une promo.

Le **modèle prêt à l'emploi** (avec notice formateur) est dans [`depot-collectif-modele/`](./depot-collectif-modele/README.md).
