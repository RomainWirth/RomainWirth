# Mon premier dépôt - Apprendre Git & GitHub par la pratique

**Kit apprenant - Version débutant**
5 jours | Git & GitHub | Aucun prérequis

> Ce kit t'apprend à **versionner un projet avec Git** et à le **publier et collaborer sur GitHub**. Tu ne te contentes pas de lire des commandes : tu construis un vrai dépôt propre, du premier commit jusqu'à ta première pull request.
>
> À la fin, tu auras un **dépôt GitHub bien tenu** et tu auras contribué à un projet collectif.

## Le projet fil rouge : *Mon premier dépôt*

Tout au long des 5 jours, tu versionnes **un petit projet de ton choix** :

- **ton site *Ma Vitrine*** si tu as suivi le kit HTML/CSS ([`../../html-css/kit-apprenants/`](../../html-css/kit-apprenants/README.md)) ;
- **ou un simple carnet de notes** en Markdown (ex : un dossier `mon-carnet/` avec quelques fichiers `.md`).

Le contenu importe peu : ce qui compte, c'est d'avoir de vrais fichiers à modifier pour pratiquer Git. Le résultat final est un **dépôt GitHub propre**, avec un historique clair, un README, des branches, et ta première **pull request** sur un dépôt collectif.

---

## Comment utiliser ce kit

- **Un jour = un fichier.** Suis les jours dans l'ordre, ils sont progressifs.
- Chaque jour contient : des **objectifs**, des **explications**, des **tâches** (commandes à exécuter dans le terminal) et un **livrable** (checklist).
- Les sections **⚡ Pour aller plus loin** sont optionnelles.
- Pas de fichier de corrections : tu vérifies ton travail avec `git status`, `git log` et l'interface GitHub. La bonne réponse, c'est un dépôt dans l'état attendu.
- Pour la théorie, appuie-toi sur le cours du dossier parent : [`../git.md`](../git.md) et [`../github.md`](../github.md).

## Prérequis techniques

- Un **terminal** (Terminal sur Mac/Linux, Git Bash sur Windows).
- **Git installé** (on le fait au jour 1).
- Un **compte GitHub** (on le crée au jour 4).
- Un **éditeur de code** (VS Code recommandé).

> 💡 **Le terminal fait peur au début, c'est normal.** Toutes les commandes sont données pas à pas. Prends l'habitude de taper `git status` très souvent : c'est ta boussole, elle te dit toujours où tu en es.

## Durée indicative

Compte une demi-journée à une journée par chapitre. Le jour 5 (collaboration) peut être fait seul (mode dépôt collectif) ou à plusieurs (mode binôme).

> ⏩ Une version **compacte en 3 jours** pourra être ajoutée plus tard.
