**Kit apprenant - Version accélérée**

## Le projet fil rouge : *Mon premier dépôt*

Tu versionnes un **petit projet de ton choix** (ton site *Ma Vitrine* du kit HTML, ou un simple carnet de notes en Markdown), tu le publies sur GitHub, et tu fais ta première **pull request** sur un dépôt collectif.

---

## Mode d'emploi

- Un jour = un fichier, dans l'ordre.
- Chaque jour : **objectifs**, **explications condensées**, **tâches** (commandes à exécuter), **livrable**.
- Sections **⚡ Pour aller plus loin** optionnelles.
- Pas de corrections : tu vérifies avec `git status`, `git log` et l'interface GitHub.
- Pour approfondir : la [version 5 jours](../git-github-5j/README.md) et le cours [`../../git.md`](../../git.md) / [`../../github.md`](../../github.md).

## Prérequis techniques

- Un **terminal** (Git Bash sur Windows).
- **Git installé**, un **compte GitHub** (créé au jour 2), un **éditeur** (VS Code).

> 💡 Réflexe n°1 : tape `git status` très souvent, c'est ta boussole.

## Collaboration (jour 3)

La pratique des pull requests se fait via un **dépôt collectif** (*Le Mur des Apprenants*) où chacun contribue, ou **en binôme**. Le modèle du dépôt collectif est dans [`../depot-collectif-modele/`](../depot-collectif-modele/README.md).
