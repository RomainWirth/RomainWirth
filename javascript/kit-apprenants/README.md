# Kits apprenants — JavaScript

Deux parcours pour apprendre JavaScript par la pratique, autour du **même projet fil rouge** : *Explorateur*, une application web qui récupère des données depuis une API publique et les affiche de façon interactive (recherche, filtres, tri, vue détail).

Le code final est le même — seul le **rythme** et le **niveau de guidage** changent.

---

## Choisir sa version

| | [Version complète — 11 jours](./javascript-11j/README.md) | [Version compacte — 5 jours](./javascript-5j/README.md) |
|---|---|---|
| **Pour qui ?** | Débutant complet en programmation | A déjà des bases (autre langage) ou apprend vite |
| **Rythme** | Progressif, détaillé | Soutenu, à l'essentiel |
| **Fondamentaux** | 5 jours (1 notion / jour) | 2 jours (condensés) |
| **Projet DOM + API** | 6 jours | 3 jours |
| **Exercices** | Nombreux, très guidés | Ciblés, plus denses |

> 💡 **En cas de doute, commence par la version 11 jours.** Tu peux toujours accélérer en sautant les sections que tu maîtrises déjà. La version 5 jours suppose que tu es à l'aise avec les bases de la programmation (variables, conditions, boucles).

## Contenu des deux kits

### [Version complète — 11 jours](./javascript-11j/README.md)

Fondamentaux (J1–J5) : variables, types, opérateurs, conditions, boucles, fonctions, tableaux, objets — un chapitre par notion, avec exercices à énoncés seuls et corrections séparées.
Projet *Explorateur* (J6–J11) : DOM, événements, `fetch`, injection des données, recherche/filtres/tri, vue détail et finitions.

### [Version compacte — 5 jours](./javascript-5j/README.md)

Fondamentaux express (J1–J2), puis projet *Explorateur* (J3–J5) sur le même déroulé, en accéléré.

---

## Le projet fil rouge : *Explorateur*

Une page web qui :
- récupère une liste d'éléments depuis une **API publique gratuite** ;
- les affiche en **cartes** (image, nom, infos) ;
- propose **recherche**, **filtres** et **tri** ;
- affiche une **vue détail** au clic.

### API disponibles (au choix)

| API | Thème | URL de base |
|---|---|---|
| **PokéAPI** | Pokémon | `https://pokeapi.co/api/v2/` |
| **Dragon Ball API** | Dragon Ball | `https://dragonball-api.com/api/` |
| **Rick and Morty API** | Rick & Morty | `https://rickandmortyapi.com/api/` |
| **TVMaze** | Séries TV | `https://api.tvmaze.com/` |

Toutes gratuites, sans clé. Tu peux aussi utiliser une autre API publique de ton choix (JSON, liste d'éléments avec image, CORS autorisé).
